MavenProject (Vue 3 + Java) — учебный full-stack проект: фронтенд на Vue 3 (Composition API), бекенд на Java-сервлетах без фреймворков. Реализовал REST API, JWT-аутентификацию, CORS-фильтры. Целью было понять, как работают сервлеты изнутри и как фронтенд взаимодействует с бекендом на низком уровне.
